# 스코어카드 점수표

연체 위험 기반 대출 승인 기준 설계 (Loan Approval Risk Scoring) — v2 재분석

재현 코드: [`v2/scripts/07_models.py`](../scripts/07_models.py) · 원본 수치: [`modeling_results.json`](modeling_results.json)의 `points_table`

> 이 점수표는 **스코어카드(로지스틱 회귀) 후보**(`scorecard_with_age`, 24개 변수)의 점수 변환 결과다. 4단계 모델 선택 규칙 적용 결과 **최종 선택은 LightGBM**이었으나(자세한 내용은 [`06_modeling.md`](06_modeling.md) 참고), 2-3절 산출물 지시에 따라 스코어카드 후보의 점수표는 그대로 작성해 남긴다.

## 점수 변환 공식

* 기준점 600점 = 정상:연체 오즈 50:1
* PDO(Points to Double the Odds) = 20
* `Factor = PDO / ln(2) = 20 / 0.6931 = 28.8539`
* `Offset = 600 - Factor × ln(50) = 600 - 28.8539 × 3.9120 = 487.1229`
* 로지스틱 회귀는 `TARGET=1(연체)`을 예측하므로, `logit(P(연체)) = intercept + Σ(β_i × WOE_i)`에서 `ln(오즈_정상) = -(intercept + Σ(β_i × WOE_i))`이다. 따라서:
  * **기본점수(Base Points) = Offset - Factor × intercept = 557.30**
  * **변수·구간별 배점 = -Factor × β_i × WOE_i**
* 신청자의 최종 점수 = 기본점수 + Σ(해당 구간의 배점)

## 변수 선택 결과(이 스코어카드에 쓰인 24개 변수)

IV≥0.02 필터와 WOE 상관 |r|>0.7 필터를 거쳐 남은 변수는 [`06_modeling.md`](06_modeling.md)의 "변수 선택" 절 참고. 아래 점수표는 나이를 포함한 24개 변수 버전(`scorecard_with_age`) 기준이다.
