# 검증 키트 실행 안내 (Mac 기준)

## 1. DuckDB CLI 설치

```bash
brew install duckdb
```

체크리스트 A절(1~4번)은 터미널에서 `duckdb` 입력 후 `SELECT ...` 쿼리를 직접 실행해서 확인한다. 저장소 루트에서 실행하면 `data/raw/...` 상대경로가 바로 동작한다.

## 2. 노트북 실행 방법

```bash
cd v2/verification
pip install jupyterlab duckdb pandas numpy   # 이미 설치돼 있으면 생략
jupyter lab verification.ipynb
```

노트북은 실행되지 않은 상태로 커밋돼 있다. 위에서부터 순서대로 셀을 실행(Shift+Enter)하면서 각 셀 위 마크다운에 적힌 기대값과 출력을 대조한다.

8·9·10·12번 항목 셀은 "내보내기"만 하고 계산 결과를 출력하지 않는다 — `exports/` 폴더의 CSV를 Numbers나 엑셀로 열어 직접 세고 계산한 뒤 `checklist.md`에 적는다.

## 3. 체크리스트 진행 순서

1. `checklist.md`를 연다.
2. A(원천 데이터) → B(분할) → C(변수, 신청자 추적) → D(가설 검증 계산) → E(원칙 준수) → F(4단계 최종평가) 순서로 진행한다 — 뒤로 갈수록 앞 단계 결과에 의존한다. F절은 `v2/data/predictions/test_scores.parquet`이 있어야 하므로(`python3 -I v2/scripts/08_final_evaluation.py`로 생성), 1~3단계 검증이 끝난 뒤 4단계 모델링·최종평가 스크립트를 실행한 다음 진행한다.
3. 각 항목을 노트북 또는 DuckDB CLI로 직접 확인하고, "실제값"·"통과"·"메모" 칸을 채운다.
4. 기대값과 다르면 `verify_log.md`에 날짜, 항목 번호, 발견한 문제, (추정되는) 원인을 적는다.
5. 수정이 필요하면 Claude Code에 무엇을 고쳐야 하는지 요청하고, 수정 후 같은 항목을 재확인해 `verify_log.md`의 "재확인 결과" 칸을 채운다.

## 4. 예상 소요 시간

| 절 | 항목 수 | 예상 시간 |
|---|---|---|
| A. 원천 데이터 | 4 | 15~20분 (대용량 CSV 스캔 포함) |
| B. 분할 | 3 | 5분 |
| C. 변수 (신청자 추적, 스프레드시트 수작업 포함) | 4 | 20~30분 |
| D. 가설 검증 계산 (스프레드시트 수작업 포함) | 3 | 20~30분 |
| E. 원칙 준수 | 1 | 5분 |
| F. 4단계 최종평가 (스프레드시트 수작업 포함) | 5 | 25~35분 |
| **합계** | **20** | **약 1시간 25분~2시간 5분** |
