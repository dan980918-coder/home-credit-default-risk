# 이전 버전(v1) 안내

이 폴더는 2025년에 진행한 부트캠프 팀 프로젝트(3명)의 모델링 결과와, 이후 개인적으로 확장한 서빙·배포·모니터링 코드를 보관한다. 범위는 EDA·변수 생성·모델링(`scripts/`, `docs/`)부터 FastAPI 서빙(`app/`), Docker 이미지(238MB, `Dockerfile`), AWS EC2 배포, PSI 기반 드리프트 모니터링 대시보드(`dashboard/`)까지다.

현재 버전(`v2/`)과는 모델과 변수 구성이 다르다. 이 안의 서빙 코드(`app/model.py` 등)는 v1에서 학습한 모델(`models/lean_a_lightgbm_v1.joblib`) 기준으로 작성돼 있어 v2 모델과 호환되지 않는다.

재분석한 이유는, v1이 이미 모델 성능과 변수 중요도를 본 뒤 거꾸로 분석 스토리를 구성한 부분이 있었기 때문이다. v2는 원데이터 점검부터 가설 수립, 신호 검증, 모델링, 최종 평가까지 결과를 보기 전에 기준을 먼저 정하는 순서로 처음부터 다시 설계했다.

이 폴더의 코드는 실행을 보장하지 않는다(의존성은 `requirements.txt`/`requirements-serving.txt`/`requirements-dev.txt`에 당시 버전으로 고정돼 있다). CI도 더 이상 실행되지 않는다(`ci.yml` 참고, 비활성화됨).
